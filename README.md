# Деньги на неделю

Отдельное простое PWA: добавляешь сумму на текущую неделю, записываешь траты — приложение само считает остаток.

## Как работает

- Неделя считается с понедельника по воскресенье.
- Кнопка **«Пополнить»** добавляет деньги в бюджет текущей недели.
- Кнопка **«Трата»** записывает расход и вычитает его из остатка.
- В центре видно, сколько осталось; ниже — бюджет, потрачено и примерная сумма на день.
- В конце недели бюджет обнуляется, а прошлая неделя остаётся в истории.
- Все данные хранятся только в браузере (localStorage), ничего не отправляется на сервер.

## Установка на телефон

Открой сайт в браузере и добавь на главный экран:

- **Android / Chrome:** меню → «Установить приложение».
- **iPhone / Safari:** «Поделиться» → «На экран “Домой”».

После установки работает офлайн.

## Локальный запуск

```bash
cd week-money
python3 -m http.server 8000
# http://localhost:8000
```

## GitHub Pages

Сайт статический, без сборки. Достаточно положить файлы в корень репозитория и включить Pages:

Settings → Pages → Source: **Deploy from a branch** → Branch: **main** → Folder: **/ (root)**.

## Файлы

```
├── index.html      # разметка
├── styles.css      # стили
├── app.js          # логика и localStorage
├── manifest.json   # PWA-манифест
├── sw.js           # service worker (офлайн)
├── icon.svg        # иконка
└── icon-192.png / icon-512.png
```
